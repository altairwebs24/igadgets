# Gadget Haven

Build a fully functional e-commerce store, the store sells gadgets for phones mainly iphones and other accessories, i want it to have these collections (trending, just in, powerbanks, covers) and an option to add more in the admin panel, ability to add more products with all picture /media set to public. with the first image being the logo and the other 2 videos as just media for the website which I want to be set to be public so that they can still show when deployed on Cloudflare, videos should auto play with no interaction button. The theme is just black and white. Also add a shopping cart, payment method is still gonna be set up
